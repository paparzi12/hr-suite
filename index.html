운영 가이드

  1. 배포 — hr-suite 폴더 전체를 GitHub Pages 저장소에 업로드하면 index.html이 허브로 열립니다. 기존 인력현황_대시보드.html을 같은 폴더에 두면 ① 카드에서 바로 연결됩니다.
  2. 대시보드 간 연동 — 같은 도메인(브라우저)의 localStorage를 공유합니다. ⑦ 리텐션·⑧ 교육은 ① 인력현황 명부를 자동으로 읽고, ⑩ 경영진 종합은 전 대시보드 지표를 자동 집계합니다.
  3. 데이터 보관 — 모든 데이터는 입력한 브라우저에만 저장됩니다(STEP 1). 각 대시보드의 엑셀 다운로드로 주기 백업을 권장하며, STEP 2에서 Firebase 공용 저장소로 전환 예정입니다.
  4. 권한 주의 — ③ 인건비·⑥ 성과평가는 민감정보입니다. 공용 PC에서는 사용 후 샘플 비우기/브라우저 데이터 삭제를 권장합니다.
